# BeschutWonen — Twijgje

Lokale demonstratie voor dagregistratie, cliëntenbeheer en conceptafrekeningen. **Gebruik uitsluitend fictieve gegevens: de demo heeft geen beveiligde login of gedeelde opslag.**

- [Download de zelfstandige demo](https://github.com/DriesProost/BeschutWonen/raw/refs/heads/main/demo/twijgje.html) en open het bestand in Edge of Chrome.
- [Handleiding](demo/LEESMIJ.md)
- [Alle bestanden downloaden als ZIP](https://github.com/DriesProost/BeschutWonen/archive/refs/heads/main.zip)
- [Ontwerp voor beveiligde Microsoft 365-toegang](docs/TOEGANG.md) — nog niet ingericht.

Middagmaal: €5. Soep: €1,50. PVT is niet betalend: alle conceptkosten blijven €0; de aanwezigheid wordt per dagdeel gerapporteerd voor de detachering van Leen.

Cliënten kunnen worden ingeschreven met contactgegevens en een PVT-vakje. De demo bevat afdrukbare cliëntenlijsten en een blanco dagblad voor handmatige registratie.

Ontwikkelcontrole: `npm test`. Optionele browsercontrole met Python Playwright en Chromium: `python3 tests/browser_smoke.py`.
